# Phonon Calculations

Two methods are outlined here for computing phonon properties using Quantum ESPRESSO: 

1. Using Density-Functional Perturbation Theory (DFPT), which is natively implemented in Quantum ESPRESSO. The steps for performing the calculations are outlined in the [phon_QE folder](https://github.com/JosephPVera/Guide-for-DFT-calculations/tree/main/Quantum-ESPRESSO/Phonons/phon_QE).

2. Using the finite-displacement and supercell approach, which can be performed using [Phonopy](https://phonopy.github.io/phonopy/qe.html). The steps for performing the calculations are outlined in the [phon_phonopy folder](https://github.com/JosephPVera/Guide-for-DFT-calculations/tree/main/Quantum-ESPRESSO/Phonons/phon_phonopy).
